VitaSync 3.0
Windows 10/11 x64

Transfer files between your PC and a PS Vita running VitaShell over FTP or USB.

What's new
- Light and Dark appearance with remembered preferences and sun/moon controls.
- Clearer file rows, photo/folder artwork and dedicated music/video images.
- Start/Clear actions, a Play icon, and smoother scrolling for long file lists.
- Drop files or folders anywhere to review them before starting a transfer.
- ZIP, RAR and supported archives are extracted locally before transfer.
- Vita data and savedata paths are preserved without an extra ux0 wrapper.
- Savedata metadata is distinguished from application metadata, including ZIPs.
- Per-item destination choices include Data, Saves, and Downloads.
- Simpler transfer progress and corrected help, focus and hover interactions.
- Vita-themed setup artwork and an optional desktop shortcut on the final page.

Setup: run the installer and follow the English wizard. The final page offers
checkboxes to launch VitaSync and create a desktop shortcut.
Portable: extract the entire RAR, then open VitaSync/vitasync.exe. Keep all
runtime libraries and folders beside the executable. No Qt installation is needed.
Compare the downloaded files with SHA256SUMS.txt. Packages are not code-signed.

Connect
FTP: set VitaShell's SELECT button to FTP, press SELECT, then enter the
address and port shown on the Vita. Use a trusted local network.
USB: set SELECT to USB, choose the storage device, connect a data cable,
and press SELECT. Choose USB cable in VitaSync and connect to the exported drive.
Safely eject USB storage when finished.

Compatibility and verification
- Core parsing, extraction, and synthetic USB routing checks pass locally.
- Local UI checks cover help, theme controls, destination selection and 400-item
  scrolling. Physical Vita USB/FTP operation remains a hardware check.
- The complete transport/device test suites are not recorded as passing:
  Kaspersky terminated their test executables during local development.
  This is not a malware-free certification or a confirmed false-positive verdict.
- Windows uses its system archive reader for non-ZIP formats. This reader can
  reject some RAR member names containing non-ASCII characters on this machine.
  ZIP and folder Unicode paths pass; rejected archives show an error.
- Encrypted or unsupported archives report an error. Other platforms need bsdtar
  for non-ZIP formats. Archive paths and extraction sizes are validated.
- Media is copied without conversion; codec support depends on the Vita.
  Android APKs are identified but cannot be installed or run on a PS Vita.
- Upload VPK packages, then open them in VitaShell to install. Folder dumps and
  savedata still require the matching console setup and permissions.
- No telemetry, accounts, cloud sync or automatic update checks. Local preferences
  and user files are excluded from the release packages.
